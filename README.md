# 🍪 GALACTIC COOKIE — The Universe's Biscuit

[![Play Game](https://img.shields.io/badge/Play-Galactic%20Cookie-FFD700?style=for-the-badge&logo=rocket)](https://galactic-cookie.jeremyracine2017.workers.dev/)

**Galactic Cookie** is an immersive *Idle Clicker* game featuring a modern, high-contrast space aesthetic. Click the cosmic cookie, gather resources, and unlock massive structures to dominate cookie production across the galaxy.

## ✨ Key Features

* **Dynamic Combo System:** The faster you click, the higher your multiplier climbs.
* **Galactic Shop:** Purchase infrastructure ranging from a simple "Cosmic Finger" to a "Sugary Black Hole."
* **Upgrades:** Boost your clicking power with telekinesis or cybernetic enhancements.
* **Prestige System (Transcendence):** Reset your progress to gain massive permanent bonuses and reach astronomical production peaks.
* **Achievements & Trophies:** Unlock badges to celebrate your most important milestones.
* **Modern Design:** Fluid interface, custom cursor, animated starfield, and particle effects.

## 🚀 Installation & Usage

This project is a static web application (HTML/CSS/JS). To run it locally:

1.  Clone the repository:
    ```bash
    git clone [https://github.com/NAGZYY/galactic-cookie.git](https://github.com/NAGZYY/galactic-cookie.git)
    ```
2.  Open `index.html` in your favorite web browser.

Or access the live version directly:
👉 **[https://galactic-cookie.jeremyracine2017.workers.dev/](https://galactic-cookie.jeremyracine2017.workers.dev/)**

## 🛠️ Built With

* **HTML5 / SVG:** Core structure and high-quality vector rendering of the cookie.
* **CSS3:** Space animations (`keyframes`), blur effects (`backdrop-filter`), and responsive design.
* **JavaScript (Vanilla):** Game logic, `localStorage` save system, and particle management.

## 📸 Interface Overview

* **Left Panel:** Shop and Prestige button.
* **Center:** The Cosmic Cookie with glow effects and milestone progress bar.
* **Right Panel:** List of unlocked achievements and trophies.
